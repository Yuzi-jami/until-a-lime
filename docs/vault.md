# 本地密码库（1.0）

更新：2026-10-07。当前权限与会话范围已包含悬浮搜索 / 保存 / 连续复制及浏览器桥接，不沿用早期“悬浮窗仅导航”的限制。

桌面首次启动创建空库，主密码至少 12 个字符（最多 1024 字节），不会自动生成或保存用户的主密码。浏览器预览仍是临时虚构数据，不连接文件密码库。

## 格式与算法

固定格式 `LIMEV001`：8 字节魔数/版本、16 字节随机盐、24 字节随机 nonce，随后是 XChaCha20-Poly1305 密文与认证标签。整个 48 字节头部作为 AAD。每次写入使用新的系统随机 nonce；盐在创建库时随机生成。

Argon2id v1.3，内存 65536 KiB、3 次迭代、并行度 1，输出 32 字节密钥；参数是版本约定，不接受文件传入的资源参数。未做本机发行版 KDF 性能标定，调试版处理主密码较慢。文件最大 8 MiB、最多 2000 条记录。对字段、编号重复和版本进行验证。

所有账号字段，包括用户名、网址、备注与收藏状态，均在密文内。前端列表只收到元数据；密码通过独立命令显式请求。主密码、密钥、解密 JSON 缓冲区及 Rust 记录密码尽量清零；WebView/IPC/分配器仍可能存在副本，不能承诺进程内明文完全不可恢复。前端从 DOM 清除输入不等于安全擦除内存。

## 文件与保存

Tauri 应用数据目录中的 `vault.lime`；Windows 通常位于 `%APPDATA%\dev.untilalime.desktop\vault.lime`，以 Tauri 解析结果为准。文件名及存在状态不是秘密。

修改先构建新数据，再加密写入同目录临时文件并同步，最后原子替换。替换成功才更新内存记录。前一版本保留到 `vault.lime.bak`。没有明文临时文件；临时文件与目录继承当前用户目录权限。强制断电、文件系统故障、恶意本机进程仍可能造成损失，原子替换不能替代外部备份。

保存前检查当前文件是否与加载版本一致，发现外部修改时拒绝覆盖，提示锁定后重新打开。单实例避免正常应用重复写入；这不是防御恶意进程竞争的跨进程文件锁。

解锁页可恢复上次加密备份：先验证备份主密码，当前文件另存为 `vault.before-restore-<随机值>.lime`，然后替换。恢复会丢弃最近一次修订，另存文件保留供排查；不自动删除或覆盖另存文件。备份不是回收站，删除的记录可能仍存在于旧密文备份中。

## 锁定与权限

账号管理、显示已有密码、删除、分类整理、导入导出和改密等命令限制 `main`。`floating` 通过专用命令搜索元数据、保存账号及将所选账号复制到剪贴板，不从前端取得完整已有密码列表。每次库访问均检查 Rust 解锁状态及闲置截止时间；保存和连续复制还绑定会话 epoch。关闭主窗口只隐藏到托盘；手动锁定、闲置到期和完全退出都会释放 Rust 密钥和解密记录，取消连续复制并清理前端页面。

主密码派生在线程池执行。锁定推进会话代数，迟到的解锁结果丢弃。后台每秒检查闲置，不依赖前端计时器仍在运行；主窗口与悬浮编辑中的活动更新同一后端时钟。支持 1–1440 分钟或关闭闲置锁定；Windows 会话锁屏 / 休眠联动按用户决定不接入。

删除撤销记录最多保留 10 秒于 Rust 内存，锁定时立即释放。最近使用顺序当前为会话级信息，账号字段和收藏持久化。

复制仅用户显式操作触发。后台以剪贴板序号判断是否仍属于本次复制，30 秒后清理；更新内容不受影响。锁定/退出会尝试提前清理。无法保证删除剪贴板历史或第三方软件已经获取的副本。

## 验证与剩余工作

Rust 测试在独立临时目录使用虚构密码库，未创建用户密码库：覆盖加密后无明文、正确/错误主密码、重开、修改保留密码、随机 nonce、覆盖拒绝、备份与恢复、损坏/截断/过大/未知版本、写入失败回滚、锁定访问拒绝、闲置超时和进行中的解锁取消。

React 测试模拟 IPC：验证确认密码、显式读取密码、锁定移除账号、迟到解锁拒绝和保存失败保留编辑表单。这些不是原生 WebView 与真实 Rust IPC 的端到端测试。

下一阶段只包括原生全流程验收、真实屏幕阅读器验收与独立安全审计；修改主密码、导出/导入已实现并覆盖自动化测试。系统锁屏联动不在范围内。尚未经独立安全审计；请先使用测试账号验证，不作为唯一密码备份。

## 修改、导入与导出

设置中的修改主密码会在线程池验证旧主密码，再用新盐和新密钥重新加密。改密成功后当前库使用新主密码，之前保留的 `.bak` 仍使用旧主密码，直到后续成功保存覆盖它。导出打开原生保存对话框，默认拒绝覆盖既有文件；导入先用临时选择票据绑定用户挑选的文件，解锁库时追加记录并重新编号，空库时用备份建立当前库。文件对话框期间锁定或会话变化会拒绝提交。

## 按需验证、浏览器与分类

默认进入不含账号信息的功能入口，密码库操作触发验证；可选启动验证。验证成功后保持会话，沿用手动/闲置/退出锁定。主密码不持久保存，列表字段仍在密文内。生成新密码和复制生成值无需读取库，因此可在未验证时使用。

浏览器使用独立、可断开的 Native Messaging 通道并检查同一个会话状态。当前匹配按 PSL 注册域处理同站子域，隔离私有后缀租户，并保持 HTTPS、端口与目标复核边界；旧 HTTP 保存记录可用于同站 HTTPS，不向 HTTP 页面填写。详情见 browser-extension.md；CSV 规则见 browser-csv.md。

分类规则作为 `category_rules` 可选字段保存在加密数据内，旧库缺省为空。1.0 支持更多分类名称；升级不会自动重分组，更新后应使用新版读写。加密封装和数据目录保持不变。

2026-10-23，1.1.0 新增加密字段 browser_preferences（旧库默认空），按去参数的页面 URL 记住上次填写账号。首次记忆后应继续使用新版；1.0 的严格 JSON 校验不识别这个新字段，不支持直接降级。LIMEV001 加密封装、算法和目录不变，升级前可导出加密备份。浏览器采集暂存不写磁盘，120 秒、锁定、退出后释放；确认更新需核对原记录未变，成功只替换密码。
