# 密码库设计

密码库位于 `%APPDATA%\dev.untilalime.desktop\vault.lime`。账号、密码、网址、备注、分类和网站偏好一起加密保存。

## 加密格式

文件格式为 `LIMEV001`，头部为 48 字节：8 字节格式标识、16 字节随机盐和 24 字节 nonce。其后为密文和认证标签，完整头部参与认证。

| 项目 | 参数 |
| --- | --- |
| 密钥派生 | Argon2id v1.3 |
| Argon2 参数 | 64 MiB 内存、3 次迭代、并行度 1 |
| 密钥长度 | 256 位 |
| 加密 | XChaCha20-Poly1305 |
| nonce | 每次保存重新随机生成，192 位 |
| 文件上限 | 8 MiB、2000 条账号 |

主密码至少 12 个字符，不写入磁盘。锁定和退出时释放 Rust 中的密钥与解密记录。

## 保存与恢复

修改先写入同目录的加密临时文件，同步后原子替换；成功后才更新内存。前一个版本保留为 `vault.lime.bak`。

写入前检查文件是否被外部修改。发现变化时停止覆盖，需要重新打开密码库。

解锁页可从上次备份恢复。恢复前，当前文件另存为 `vault.before-restore-<随机值>.lime`。设置中还可以导出加密备份，或将备份中的账号导入当前库。

修改主密码会使用新盐和新密钥重新加密当前库。之前导出的备份仍使用当时的主密码。

## 会话与命令

所有密码库操作由 Rust 检查解锁状态和闲置截止时间。锁定会推进会话编号，取消待处理的保存、导入和解锁请求。

主窗口提供账号管理、密码查看和数据维护。悬浮窗通过专用命令搜索、保存和复制。浏览器请求检查扩展来源、网站和目标账号；待确认密码最多保留 120 秒。

复制后 30 秒，应用会检查剪贴板是否仍是自己写入的内容，再清理它；系统或其他软件的剪贴板历史需单独管理。

## 版本兼容

1.1 增加 `browser_preferences` 字段，按页面来源与路径记忆上次填写账号，忽略查询参数和片段。旧库可由 1.1 读取；写入该字段后，1.0 无法读取，请使用 1.1 或更高版本。
