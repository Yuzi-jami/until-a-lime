# 桌面开发预览

> 当前阶段以 [plan.md](plan.md) 为准。本地加密库 B1 已接入，见 [vault.md](vault.md)。以下包含旧设计与历史验证状态；演示数据、UI 锁定等旧描述仅适用于早期版本或浏览器预览。

正式源代码位于 `src/`（React / TypeScript）和 `src-tauri/`（Rust / Tauri 2）。`ui-prototype/` 保留为早期设计对照，后续功能开发以正式源码为准。

## 构建

需要 Node.js、Rust stable MSVC、Visual Studio C++ 构建工具、Windows SDK 与 WebView2。

```powershell
npm ci
npm run build
npm run tauri -- build --debug --no-bundle
pwsh -NoProfile -File scripts/Start-LimeDesktop.ps1
```

Rust 安装后应重新打开终端，使 Cargo 加入 PATH。首次构建会下载依赖，Cargo.lock 与 package-lock.json 应一起纳入版本管理。调试构建产物为 `target/debug/until-a-lime.exe`，内嵌页面，无需网页开发服务；Windows 仍需安装 WebView2。该产物尚不是签名安装包。

网页开发：`npm run dev`，本机端口 1420。桌面热更新：`npm run tauri -- dev`，不要同时启动重复的 1420 服务。

## 当前行为

- 搜索、分类、收藏、最近使用、编辑虚构账号、轮盘、随机字符展示、界面锁定。
- 深浅色偏好保存到 localStorage；账号记录只在页面内存中，不持久化。
- 侧栏“收藏室设置”提供浅色、深色、跟随系统主题，并同步到悬浮窗；旧主题偏好保留。侧栏快速切换将改为手动浅/深色。
- 自动锁定默认 5 分钟，可选 1/5/15 分钟或关闭，偏好保存到 `lime.autoLock`。按主窗口内鼠标、键盘和滚动计时；检查聚焦、可见性变化及休眠后的时间差，不监视系统全局输入。锁定会收起密码、面板和撤销通知，仍仅是 UI 演示锁定。
- 新增与编辑支持名称、用户名、分类、网站和便笺；拒绝纯空白的必填内容。
- 账号详情支持删除，确认框展示名称和用户名，默认聚焦“保留账号”。删除后选中相邻账号，10 秒内可撤销最近一次删除；撤销恢复账号、收藏及原最近使用位置，不覆盖其他编辑。锁定会关闭撤销入口；账号编号在当前会话中不复用。空列表支持直接添加。
- 切换账号或锁定会隐藏演示密码。锁定只是展示状态，不构成密码库安全边界。
- 密码生成器支持 8–64 位滑杆、大写/小写/数字/符号选择、排除易混淆字符；至少保留一种类型，每种选中的类型至少出现一次。使用 Web Crypto，字符映射和整段候选均采用拒绝采样，避免取模或强制插入字符造成的偏差。桌面生成器支持显式复制，尚未接入保存。浏览器预览禁用复制。
- 桌面版提供独立透明置顶轮盘：鼠标移到橙子展开，点击中心固定展开，Esc 收起；切换到其他窗口也会收起。直接按住橙子图标拖动窗口；移动超过约 6 个屏幕 CSS 像素才触发原生拖动，轻点保持固定轮盘的行为，拖动后抑制误点击。
- 轮盘可以打开收藏室、搜索、随机字符生成器与演示锁定。锁定期间先返回主界面解锁，再使用搜索和生成器。
- 关闭主窗口只隐藏演示界面并保持解锁；左键托盘橙子重新打开，右键可显示或隐藏轮盘、锁定、退出应用。
- 单实例运行：再次打开 EXE 或启动脚本时，恢复已有主窗口，不新建托盘和轮盘。已有界面锁定状态保持不变；第二次启动的参数不会触发填写或解锁。
- 轮盘位置在关闭主窗口、隐藏轮盘或托盘退出时保存到应用配置目录的 `floating-position.json`，仅含格式版本与橙子中心坐标。下次启动恢复；配置损坏或原显示器断开时回到主屏可见位置。强制结束进程可能丢失尚未保存的位置。
- 托盘菜单提供“重置悬浮轮盘位置”，将轮盘移回主屏并显示。缩放或工作区变化时限制位置，避免恢复到屏幕外；多显示器与实际 DPI 切换仍需实测。
- Rust 仅提供运行环境、应用内导航和窗口控制命令。无通用文件、剪贴板、shell 插件权限，不依赖旧 windows-validation 包，不注册全局热键，不模拟输入。
- 浏览器预览继续使用页面内轮盘。桌面轮盘收起为 96 × 88，展开为 300 × 310（逻辑像素）。调整尺寸时保持橙子中心位置，超出当前显示器工作区时向内修正。尚未实现空白区域鼠标穿透或边缘吸附，展开时仍有透明矩形占用。

QQ 保护输入框与旧蓝屏事件保持未解决状态；不要将当前 UI 构建成功理解为旧输入功能已修复。

## 生成器复制

仅主窗口可调用受限复制命令，接受 8–64 位可见 ASCII 字符。点击复制后，Rust 后台在 30 秒后检查剪贴板序号，仍匹配才清空；即使后来复制的内容恰好相同，只要 Windows 序号变化也保留。序号比较和清空在同一次剪贴板锁内执行，不读取其他剪贴板内容。再次复制会更新计时；关闭面板不停止计时。

清理时剪贴板被占用会在两秒内重试，失败时向仍打开的生成器反馈。正常托盘退出会立即尝试清理本应用待清理项；强制终止或崩溃可能来不及清理。清理仅针对当前系统剪贴板，不保证删除系统历史或其他管理器已保存的副本。账号详情复制仍是演示按钮。

复制更新验证：Clippy、8 项 Rust 单元测试和前端构建通过。新增测试覆盖复制参数边界和序号所有权判断；尚未实测系统剪贴板写入、30 秒清理及竞争场景，不能将单元测试视为完整端到端验证。
