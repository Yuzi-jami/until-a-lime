# Edge / Chrome 扩展

## 安装

1. 打开酸橙的“浏览器插件”页面，点击“准备浏览器扩展”。
2. 打开 `edge://extensions` 或 `chrome://extensions`，开启开发者模式。
3. 选择“加载解压缩的扩展”，选中应用给出的扩展文件夹。

安装一次即可。桌面升级后，在浏览器扩展管理页重新加载扩展，再刷新网页。当前扩展版本为 0.3.0。

## 填写账号

解锁收藏室，在 HTTPS 网站点击登录输入框，选择酸橙显示的账号。也可以点击工具栏橙子，或使用 Alt + Shift + L 打开账号列表。

建议优先显示当前页面上次选择的账号，其次是当前子站和路径匹配的账号，再显示同站其他账号。嵌入页面中的登录框按它自己的地址匹配。

例如，`login.example.com` 的账号会排在其他 `example.com` 子站前。同页有多个账号时，选择一次，下次便会优先显示它。

## 保存与更新

提交登录、注册或改密表单后，插件会显示保存提示。确认网站操作成功，再点击“保存账号”或“更新密码”。

- 已有相同账号和密码时，不重复提示。
- 更新密码会保留原分组、备注和收藏。
- 改密页没有用户名时，可以选择要更新的账号。
- 也可以点击工具栏中的“保存当前页面账号”。

待确认内容保留约两分钟，锁定后清除。解锁后可以重新提交，或使用手动保存入口。

## 常见问题

**没有出现账号建议？** 确认收藏室已解锁，记录的网址与当前网站对应。多步登录或特殊输入控件可以使用悬浮窗复制。

**快捷键没有反应？** 在 `edge://extensions/shortcuts` 或 `chrome://extensions/shortcuts` 修改扩展快捷键。

**关闭了酸橙还能使用吗？** 已连接的扩展会在需要时启动桌面程序；密码库锁定时仍需解锁。

**如何停用？** 在应用内点击“断开浏览器连接”；卸载扩展则在浏览器的扩展管理页操作。
