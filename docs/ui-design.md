# 直到密码变成一颗酸橙 · UI 方向 01

用户确定名称与方向：以《明日方舟》「直到大地变成一颗酸橙」活动为灵感，主窗口与悬浮轮盘统一，适度圆角。本轮未取得活动截图，不声称复刻其实际配色或布局；先用原创酸橙切面、档案编号、细网格与纸张质感完成可评审版本。后续可根据用户参考图校准。

## 视觉规则

- 按用户反馈改为暖橙方案：奶油纸白 #FAF5EC、浅暖橙 #FFC16B、深棕墨色 #3D3028，辅助焦橙 #AB561C；柑橘切面使用 #E88928。
- 窗口卡片 10–14px 圆角，输入框 6–8px；避免全界面胶囊按钮。
- 中文标题配细小英文索引，保持内容阅读优先。用柑橘切面连接标识、封面和悬浮入口。
- 主窗口三栏：分类、账号列表、详情。窄窗口下导航横排、详情移到列表下方。
- 深色沿用相同层级，不简单反转图形色彩。减少动态效果时尊重系统设置。

深色修正：明确 body 的前景色继承，采用炭灰背景 #1F1D1A、卡片 #282521、详情 #2E2924 和浅暖文字 #F3EADE。橙色用于操作与局部强调，封面改成暗底橙切面；导航选中态、输入框、轮盘、弹窗和锁定页单独适配。浏览器抽查标题、便笺、账号名、字段、主按钮与导航选中态，文字对比度最低 6.77:1；这不是全页面无障碍审计。

## 收藏室工作台（当前实现）

2026-09-29 交互修正：右上角英文标识替换为悬停/键盘聚焦显示的 Windows 窗口按钮，左侧交通灯保留，关闭仍隐藏到托盘。悬浮窗使用统一的 Compact/Wheel/Panel/Notice 原生尺寸与橙子中心坐标，提示在果实下方独立区域展示，普通结果 4.5 秒、错误 6 秒后收起，连续复制仍最多等待 20 秒。靠近屏幕工作区四边时半隐藏，悬停展开；搜索和提示不在半隐藏窗口内显示。贴边窗口本身保持在工作区内，以裁剪半颗橙子实现，避免漏到相邻显示器。

拖动回归修正：Windows 拖动命令等待系统移动循环结束后才返回，不能把 Tauri `start_dragging()` 的返回视为鼠标释放。拖动期间冻结窗口布局，结束后由唯一串行队列收起并重新判断贴边；半隐藏果实保留原裁剪中心到坐标换算完成。前端只在对应原生布局应用后切换 CSS 锚点，避免先移动图案、后移动窗口造成偏移。

拖动时的视觉保持单颗橙子：超过拖动阈值后立即隐藏轮盘背景与四个按钮，并移除其键盘焦点入口；仅隐藏菜单，不改变原生尺寸和中心坐标。松手后仍收起，下一次悬停可重新展开。

贴边过渡：拖动结束后锁住悬停和焦点自动展开，鼠标离开再进入才重新唤出菜单。靠边吸附/从边缘展开采用 230ms 减速滑动，在覆盖起止位置的临时透明窗口中完成，结束后再裁为半隐藏尺寸；不逐帧移动原生窗口，也不拖慢跟手移动。展开时果实先滑出，菜单再用 130ms 淡入；普通收起先给菜单 90ms 淡出。系统开启“减少动态效果”时直接切换。托盘重置位置会取消旧动画和旧的提交序号。

- 主窗口使用无边框 Tauri 窗口与自绘顶部栏：左侧为关闭/最小化/最大化控制，中间显示应用名，右侧显示当前环境。关闭按钮仍按应用约定收起到托盘；浏览器预览中的窗口按钮禁用。
- 内容采用三栏工作台：左侧“全部密码、收藏密码、浏览器插件、密码统计、设置、密码生成器”，中间账号列表，右侧账号详情。账号列表保留搜索、分类与收藏；浏览器插件和设置现在可作为完整页面打开。
- 详情区域的密码强度使用八瓣橙子切面展示，不显示“弱密码”“快熟了”等警示或拟人化标签。统计页只展示数量、分类分布和强度分布，配色采用中性暖色。
- 强度由 Rust 在密码库解锁后按长度、字符多样性和少量常见模式生成有界的 0–8 视觉估算，只返回账号编号和分值；不把密码或哈希发送到前端。它不是熵证明、泄露检测或安全保证。

## 轮盘

图标更新：左上角和悬浮入口使用无叶片、无果梗的橙子切面，重新居中。悬停或键盘焦点时每 5 秒旋转一周，移开暂停；只旋转图案，不旋转轮盘按钮。尊重系统减少动态效果设置。原始预览与 React 源码均同步。

中心酸橙圆钮，悬停展开四向入口：寻找账号、生成密码、锁定、收藏室。移出 350ms 后收起，点击中心固定展开；Tab 可到达选项，Esc 收起。触屏使用点击。

当前轮盘是网页内的视觉和交互预览，不是系统置顶窗口；后续用 Tauri 独立窗口实现拖动、屏幕边缘避让、DPI 适配与托盘入口。轮盘不自动执行任何填密码动作。

## 已实现的可评审交互

搜索与分类、账号详情、收藏、模拟数据添加和编辑、快捷搜索弹窗、生成器展示、锁定/返回、深浅色、轮盘。复制按钮仅展示反馈，不写入剪贴板。没有本地存储，也没有密码库、Rust IPC、全局热键或模拟输入。

## 运行与验证

运行 `node ui-prototype/server.cjs`，本地端口 4173。也可直接打开 `ui-prototype/index.html`。无需安装前端依赖，未引用外部字体、图片或活动资产。

JavaScript 语法检查通过；浏览器验证了轮盘展开、搜索 Steam 并跳转详情；1360px 桌面宽度下三栏没有横向溢出，默认窄视口可看到自适应导航和单栏列表。本轮不执行系统填写测试。
