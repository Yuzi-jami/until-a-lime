# 浏览器密码 CSV 导入

先验证收藏室，在“收藏室设置 → 导入浏览器 CSV”选择 Edge/Chrome 密码管理器导出的 CSV，检查新增和跳过条数，再确认一次性加密保存。

支持截图所示的 `name,url,username,password,note`，也支持省略 name/note、notes 列名、列重排、大小写及表头两侧空格、对应中文列名。url、username、password 三个表头必须存在，用户名单元格可以为空。HTTP/HTTPS、路径、查询参数和不同登录地址原样保留；不执行网址访问，不按域名强行合并账号。

支持 UTF-8（可带 BOM）和带 BOM 的 UTF-16 LE/BE，自动识别逗号、分号或制表符分隔，以及 Excel 的 sep= 提示；支持引号转义、逗号密码、多行备注和缺省的尾部备注单元格。密码和用户名不裁剪空白，不转换数字字符串，保留前导零。未知编码不会按乱码强行导入。请直接选择浏览器导出的原始 `.csv`，即使它默认用 Excel 打开也无需另存；真正的 `.xlsx/.xls` 工作簿不作为 CSV 解析。Excel 已经修改的前导零等内容无法从损坏副本恢复。

预览只将条数、文件名、无用户名记录数量及选择票据发送前端，密码留在 Rust 处理。预览最多保留 10 分钟；锁定、取消会清除，过期拒绝提交。源 CSV 不会被修改或自动删除。

完全相同的网址、用户名、密码视为重复；同账号不同密码保留为独立记录。所有新增记录重新编号。字段无效、超长、超限或缺少必需列/单元格、重复关键表头、多余单元格等歧义会整体拒绝，不静默截断、不先写入部分。文件限制仍为 8 MiB、2000 条；名称/网址放宽到 8192 字符、用户名 1024、备注 16384，密码仍为 1–4096 字节且不能为空。无 name 时使用网址作为名称，两者均空时显示“未命名账号”。错误标明记录序号与超限字段，不回显凭据。

收藏室编辑同步支持空用户名和较长字段，导入后再次编辑不会被旧规则拒绝。悬浮窗选择无用户名记录时直接复制密码，不启动 Tab 等待；普通记录仍按用户名 → Tab → 密码的 20 秒流程处理。旧库可由新版直接打开，无需迁移加密格式；含新增允许数据的库需使用新版打开。

CSV 是明文文件；完成后自行保管或删除。测试只用虚构数据，不能把真实导出文件提交到仓库或放进日志。加密 .lime/.bak 导入仍独立保留，无需重复开发或改变格式。
