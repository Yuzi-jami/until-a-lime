# 导入浏览器密码

1. 从 Edge 或 Chrome 的密码管理器导出 CSV。
2. 解锁酸橙，进入“设置 → 导入浏览器 CSV”。
3. 选择文件，查看新增和重复条数，确认导入。

直接选择浏览器导出的原始 CSV 即可，无需先用 Excel 打开或另存。

## 支持的格式

必需列为 `url`、`username`、`password`，可选列为 `name`、`note` 或 `notes`。支持对应中文表头、列重排、逗号 / 分号 / 制表符分隔，以及 UTF-8 和带 BOM 的 UTF-16 文件。

用户名可以为空。账号中的前导零、用户名和密码的空格、多行备注会保留。Excel 工作簿（.xlsx / .xls）需先导出为 CSV。

网址、用户名和密码都相同的记录会跳过；同账号的不同密码保留为不同记录。新账号导入到“未分类”，之后可使用 [分类整理](quick-save-and-categories.md)。

文件有格式问题时，会提示记录序号和字段。单个文件最多 8 MiB、2000 条记录。

CSV 包含明文密码，导入完成后请妥善处理原文件。日常备份可使用应用内的“导出加密备份”。
