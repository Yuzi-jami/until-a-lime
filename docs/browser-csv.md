# 浏览器密码 CSV 导入

先验证收藏室，在“收藏室设置 → 导入浏览器 CSV”选择 Edge/Chrome 密码管理器导出的 CSV，检查新增和跳过条数，再确认一次性加密保存。

支持 UTF-8/BOM、逗号、引号转义和多行备注；必需列 url、username、password，可选 name、note/notes（支持相应中文列名）。只将条数和文件名发送前端，密码留在 Rust 处理。预览最多保留 10 分钟；锁定、取消会清除，过期拒绝提交。源 CSV 不会被修改或自动删除。

完全相同的网址、用户名、密码视为重复；同账号不同密码保留为独立记录。所有新增记录重新编号。遇到字段无效、超长、超限或错误文件时整体拒绝，不静默截断、不先写入部分。沿用现有库限制：8 MiB、2000 条、名称 40 字符、用户名 80、网址 160、备注 240、密码 1–4096 字节；用户名必须非空。无 name 时使用网址作为名称，超长需调整源副本后重试。格式限制意味着部分浏览器记录不能直接导入，错误会标明记录序号但不回显密码。

CSV 是明文文件；完成后自行保管或删除。测试只用虚构数据，不能把真实导出文件提交到仓库或放进日志。加密 .lime/.bak 导入仍独立保留，无需重复开发或改变格式。
