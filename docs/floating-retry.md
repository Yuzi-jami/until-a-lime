# 悬浮入口与延时填写（手动重试）

蓝屏原因未解决。本版仅做编译和静态检查，不运行模拟输入自测。使用固定虚构凭据，不提交登录。

1. 先激活 QQ，并点击账号框或密码框。
2. 点击左侧置顶小窗口“填写”，搜索 QQ。悬浮窗口使用 NOACTIVATE，不主动抢走原应用焦点。
3. 选择“5秒后填密码”，面板收起。
4. 在 5 秒内点击同一个 QQ 窗口里的空密码框，松开鼠标、键盘，等待输入。

悬浮窗口标题显示剩余秒数。再次点击它或按住 Esc 可取消；倒计时期间每 50ms 检查原窗口和进程，其他窗口成为前台即取消。到期只向用户当前定位的原窗口输入，不主动恢复窗口，不发送 Tab 或 Enter。

限制：计时检查是采样，不能保证捕获极短暂的窗口切换；Windows 原生焦点不能证明用户点击的是密码框。按下瞬间的 Esc 也可能落在采样间隙，建议点击悬浮入口取消。尚未验证 QQ 接收结果。若原焦点捕获失败，面板仍显示但按钮禁用，可先点击 QQ 账号框后再点击悬浮入口。

日志 quickfill-retry.log 只记录固定阶段与时间，不记录输入内容。旧的热键入口仍保留，自动测试入口仍禁用。
