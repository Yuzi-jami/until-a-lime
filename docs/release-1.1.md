# 1.1.0 版本说明

2026-10-23，Windows x64，桌面 1.1.0 / 扩展 0.3.0。本轮只处理浏览器账号保存 / 密码更新，以及同站子站账号排序。[下载 v1.1.0](https://github.com/Yuzi-jami/until-a-lime/releases/tag/v1.1.0)。已发布的 v1.0.0 标签与文件不变。

## 行为

- 常规 HTTPS 登录、注册或改密表单提交后显示酸橙提示。确认网站操作成功后点击保存 / 更新，直接写入本机加密收藏室。相同账号密码不反复提示。
- 工具栏新增“保存当前页面账号”，并可取回同一来源内跳转后的待确认提示；复杂控件仍可用悬浮窗保存。锁定时需先解锁并重新提交或手动保存，不缓存待解锁密码。
- 更新只替换明确选择的账号密码，保留备注、分组和收藏。相同主站的不同子域不会在保存时自动合并。
- 账号建议和工具栏使用相同排序：当前页面上次成功填写的账号优先，其次当前主机与路径、路径前缀、当前主机、同注册域其他子站。iframe 按实际登录表单地址排序。
- 比如 `iam.wit.edu.cn/login/` 的匹配账号会排在其他 `wit.edu.cn` 子站前；同页多账号选择一次后，下次优先显示所选账号。网站参数与片段不纳入记忆，不保存链接中的临时登录参数。

## 升级与试用

1. 在旧版设置中导出加密备份，从托盘退出旧实例。
2. 在版本页下载并安装 `Until-a-lime_1.1.0_x64-setup.exe`。应用标识与数据目录保持不变；发行文件与本地构建的中文名安装包内容一致。
3. 启动新版并解锁收藏室。已有连接会更新扩展文件；若未连接，先在浏览器插件页准备扩展。
4. 在 Edge / Chrome 扩展管理页重新加载酸橙，确认版本 0.3.0，按浏览器提示允许新增权限，再刷新已打开的登录页。无需每次登录都重新加载。
5. 检查学校登录页的账号顺序；首次选择正确账号填写后，再次打开建议应优先显示该账号。可用测试账号验证新建与改密保存。

网站偏好新增在加密库内，旧库可由新版读取。首次记忆后，旧版 1.0 的严格格式校验不认识新字段；应继续使用新版。如需回退，只能使用升级前导出的独立加密备份，回退会丢失升级后的变更，不要直接覆盖日常库。
