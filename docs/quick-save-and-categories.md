# 保存账号与分类整理

## 快速保存

在橙子轮盘选择“保存账号”，填写网站或应用、用户名和密码。密码框旁的“生成”可以生成新密码并回填。

分类可以留空，保存后归入“未分类”；也可以选择已有分类或新建。网站有分类建议时，点击建议即可采用。

同一网站、同一用户名已经存在时，可以选择更新已有密码或另存一条。更新会保留原来的备注、收藏和分组。

切回网站时，小窗会保留草稿；关闭小窗、锁定或退出应用会清除草稿。

## 整理分类

单个账号可在详情页点击“分组 · 更换”。

批量整理入口位于收藏室列表上方，提供两个页面：

- **按建议整理**：对照当前分类和建议分类，勾选后统一应用。
- **手动分组**：搜索、选择多个账号，统一移动到指定分类。

“更多”中可以选择记住网站分类。之后同一网站会优先采用你保存的规则。

新导入的账号默认归入“未分类”；已有账号的分类由你选择是否调整。
