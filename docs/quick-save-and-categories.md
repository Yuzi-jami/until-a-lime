# 悬浮保存与分类整理（2026-10-01）

## 使用

- 解锁收藏室后，橙子轮盘右侧为“保存账号”。打开的是独立悬浮小窗，不打开主窗口。
- 输入网站或应用名称、可选账号及密码。网址可以省略 https://，名称默认来自域名。分类默认留空，保存时归入“未分类”；下拉始终提供完整分类列表和“新分类”入口。网站建议以独立按钮显示，点击后才选入，可自定义 1–24 字名称。
- 密码框旁“生成”打开二级面板，“使用密码”回填，“使用并复制”回填并通过现有剪贴板服务复制，30 秒后按剪贴板序号尝试清理。
- 小窗失焦时保留当前草稿，便于切回注册页面；注册成功后再点“加密保存”。草稿不写 localStorage 或文件，关闭小窗、锁定或退出会丢弃。保存失败保留草稿。
- 同一网站和相同账号出现重复时，必须选择更新某条已有密码或另存。更新只替换密码，沿用后端最新名称、分类、收藏和便笺；不会按旧前端快照覆盖元数据。
- 收藏室列表上方“整理分类 · 建议与批量修改”分为“按建议整理”和“手动分组”。前者仅列出需要修改的记录，直接并排展示当前 → 建议，默认勾选，可逐条取消后点击底部应用；后者显示当前分类，选择记录及目标分类后移动。搜索/范围切换会重置选择，底部操作固定可见，只有列表滚动。
- 1.0：账号详情新增“分组 · 更换”，直接选择已有分组或输入自定义名称，不必打开完整编辑表单。批量修改不再默认选“工作”；默认不记住网站规则，需显式勾选。纠正分组时会移除与原分组一致的旧网站规则，避免错误记忆继续生效。
- 对已有误分：进入“按建议整理”，选择“全部账号”，直接核对列表中的当前 → 建议，再点击底部“应用 N 项建议”。整批修改一次提交，未知用途与已经正确的账号不变。网站记忆来源与记住开关收在“更多”，说明集中到“使用方法”。
- 旧版 CSV 导入默认分类为“生活”，不能可靠区分手动分类与默认值，因此保留原记录，可选择“全部账号”整理。新 CSV 导入分类为“未分类”。本轮没有对真实记录做批量迁移。

## 实现边界

- 网站分类规则以精确主机名（忽略 www. 和路径）或应用名为键；内置知名域名规则允许其子域名，检查点分隔边界，不按不受限字符串包含来判断。规则不影响浏览器凭据授权域名逻辑。
- 规则存储在现有加密数据内的 `category_rules` 可选字段，读旧库/备份时默认空映射，仍使用同一加密封装。旧版程序不认识该字段及新增分类，因此更新后的库应使用新版读写。
- 手动批量分类在 Rust 内一次提交，写盘失败不更新内存；不把密码交付给分类面板。1.0 的分组接口携带原分组用于并发检查，预览后任何目标记录的分组变化则整批拒绝。显式选择记住时，相同网站不能在一批操作中指定冲突规则。
- 快速保存上下文只有元数据、分类规则与会话序号。保存时在后端锁内核对会话序号、闲置期限、处理状态和解锁状态，锁定后重新解锁不能让旧请求生效。
- 悬浮窗仅新增保存、读取保存上下文及活动通知权限；显示已有密码、删除、导出、导入等命令仍限制在主窗口。生成密码可从 main/floating 复制，不读取库中密码。
- 原生闲置计时作为桌面多窗口的统一依据。编辑小窗内的键盘和指针操作更新活动时间，不修改用户设置的时长；浏览器演示保留前端闲置计时。
- 保存后广播元数据变化，主窗口重新获取列表。小窗为 360×560 逻辑像素，并按工作区限制尺寸，内容可以滚动；轮盘原有拖动/吸附尺寸不变。
- 1.0 未添加浏览器“保存当前网站”入口，也不从活动浏览器抓取账号或密码；该入口属于可选后续功能，本次收尾不继续实现。

## 手动验收建议

2026-10-01 分类库扩充：公共服务域名规则独立到 `src/category-catalog.ts`，共 109 条，具体子域名优先，保留用户已确认规则的最高优先级；增加高校学术域名后缀规则。未知 IP、localhost、未知镜像和短域名不猜测用途。整理面板的“查看待识别域名”在本机生成当前范围的去重域名清单，剥离用户名/密码、路径、参数和片段，不读取密码，也不自动复制或上传。

使用虚构测试账号：从橙子打开保存小窗 → 生成并复制 → 切回普通文本页面 → 返回保存 → 主窗口能找到新记录；重复保存时分别尝试更新与另存；主窗口锁定后小窗关闭。用测试条目验证整组分类、多选自定义分类及重新解锁后的规则记忆。真实账户无需提供给开发工具。
