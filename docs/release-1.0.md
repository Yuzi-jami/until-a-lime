# 直到密码变成一颗酸橙 1.0.0

首个 GitHub 版本，2026-10-06。适用于 Windows x64。桌面版本为 1.0.0，Edge / Chrome 扩展独立版本为 0.2.0。这是个人使用与课程设计的 1.0 里程碑。

## 日常使用

- 本地加密账号收藏室：主密码解锁、收藏、搜索、编辑、删除撤销、强度统计、闲置锁定及备份。
- 橙子悬浮轮盘：寻找账号、保存账号、打开收藏室、锁定；直接拖动图标，贴边半隐藏。
- 允许粘贴的普通应用：选择账号复制用户名，20 秒内按 Tab 准备密码，再由用户粘贴。受保护输入框不适配。
- 悬浮保存：网站、账号和密码快速录入，生成器位于二级面板；重复账号需选择更新或另存。
- Edge/Chrome：HTTPS 登录建议，支持 iframe，同站匹配和本机桥接自动恢复；锁定时需先解锁。
- 浏览器 CSV 导入、加密备份导入导出、主密码更换、浅色/深色主题、自定义闲置时长。

## 分类和小窗

保存账号时分类默认留空，保存后归入“未分类”；完整下拉列表可选择已有分类，也可新建。网站建议由用户显式采用。

整理页分为“按建议整理”和“手动分组”：先查看当前 → 建议，再一次应用所选变化；手动页面支持搜索、筛选、多选和移动。底部操作固定可见，更多规则和使用方法按需展开。详情页也可直接更换分组。

旧版本的默认“工作”分组和隐式记忆已修正。现有账号不会在升级时自动重分类；用户可按公共网站用途重新预览建议，未知网站保留原分组。

## 下载和开始使用

- `Until-a-lime_1.0.0_x64-setup.exe`：当前用户安装包。
- `SHA256SUMS.txt`：安装包的 SHA-256 校验值。

首次进入收藏室创建主密码。关闭主窗口只隐藏到后台；有效会话内再次打开不重复验证。完全退出、手动锁定或闲置到期后需要重新输入主密码。

普通应用连续填写：在悬浮窗选择账号后粘贴用户名，20 秒内按 Tab，再粘贴密码。只支持允许复制粘贴的输入框，不自动提交。

浏览器扩展首次需在桌面设置中准备，然后由用户在 Edge / Chrome 扩展管理页确认加载。之后 HTTPS 输入框可自动显示账号建议；首次加载与新增权限确认不能省略。扩展未上架商店。

## 更新与验证边界

安装标识、AppData 路径和加密封装保持不变；升级前建议导出加密备份，再从托盘退出旧实例。Debug 和 Release 共用同一个密码库。主密码遗忘无法恢复。

发布前检查通过：前端 67 项（React 41 / Node 26），Rust 42 项（库 40 / host 2），前端构建、格式检查和 Clippy all-targets。测试只使用虚构数据。

安装包未签名，可能出现 Windows SmartScreen 提示；缺少 WebView2 时安装器需要联网下载微软引导程序。未完成独立安全审计、独立安装/升级/卸载验收、全部真实网站登录或完整原生兼容性验收。具体证据见 [验收记录](https://github.com/Yuzi-jami/until-a-lime/blob/v1.0.0/docs/acceptance-report.md)。

QQ 等受保护输入框、系统锁屏联动、浏览器“保存当前网站”入口、同步、多设备、安卓不在 1.0 范围内。项目沿用仓库现有可见性；尚未授予开源许可或完成素材权利核验。
