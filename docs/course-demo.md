# 课程演示与已知限制

需求：离线 Windows 密码收藏、检索、生成、加密备份；隐藏保留会话，手动/闲置/退出锁定。非目标：云同步、安卓、Hello、系统锁屏联动和自动提交登录。

架构与数据流见 architecture.md，测试证据见 acceptance-report.md。演示必须在单独 Windows 测试用户或虚拟机执行，不操作日常用户库。

1. 构建并启动 release，首次创建虚构测试库；演示确认密码错误。
2. 添加虚构账号、搜索、编辑、收藏、删除与 10 秒撤销。
3. 关闭闲置锁定，隐藏恢复三次；再设 1 分钟，隐藏超过期限，检查解锁页。
4. 导出新文件、改主密码、退出重开；展示新密码成功、旧密码失败。解释旧备份密钥。
5. 导入追加、取消文件选择；在临时副本演示上一备份恢复。
6. 展示主题、键盘焦点与无叶橙子轮盘；托盘退出。

以上是待执行演示步骤，不是执行记录。多屏、读屏、安装升级卸载尚待原生测试。没有填写兼容性或性能数字；不得使用真实账号截图。
