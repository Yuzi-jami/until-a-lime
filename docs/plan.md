## 后续可独立验收的工作

这些工作尚未完成，但不作为已完成实现或首发的证明。需要时再启动验收阶段，使用虚构记录和独立 Windows 测试用户 / 虚拟机，不对日常密码库做故障实验。

1. 安装、同版本覆盖、升级、卸载、WebView2 缺失场景；记录实际 AppData 保留行为。
2. 原生密码库创建 / 编辑 / 改密 / 导入导出 / 恢复、关闭恢复及闲置到期，复核迟到请求被拒绝。
3. Edge / Chrome 实际加载与权限、目标站点登录框、iframe、重启恢复和锁定；只记录实际验证的网站及浏览器版本。
4. 普通应用剪贴板、Tab 等待取消、焦点切换、多显示器 / DPI、键盘与真实屏幕阅读器体验。

已发布标签及安装包保持固定；后续应用代码修复应创建新版本并重新构建，不替换 v1.0.0 的历史产物。

## 暂不推进的产品与发布事项

- 浏览器“保存当前网站”与更新已在 1.1.0 接入；下阶段只需用户试用与实际站点验收，不重复实现。
- 项目许可证、素材权利确认和私密安全反馈渠道需所有者作决定；现有私有仓库首发不代表已开放许可。
- 签名、独立安全审计、扩展商店上架尚未完成，不在此次收尾中自动购买或提交。
- 受保护输入框、系统锁屏 / 休眠联动、安卓、同步、多设备维持范围外。

## 接手规则

先核对本地分支、远端提交和当前代码。按大阶段汇报；保留橙色与现有 UI，不顺带重构或升级全部依赖。明确区分实现、自动检查和人工验收，不读取真实库、凭据、桥接 token 或浏览器个人资料。软件开发和 GitHub 发布在开发对话处理，工程实训文档在作业对话处理。
