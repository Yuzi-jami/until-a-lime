# 兼容性矩阵

2026-10-07。下面区分当前实现与实测证据；浏览器 / 目标应用版本未系统采集，不宣称全部兼容。

| 目标 | 状态 | 证据 |
| --- | --- | --- |
| Edge | 扩展与 CSV 已实现；完整原生验收待补 | HTTPS 建议、iframe 和同站授权有虚构 DOM / Rust 测试，不等于全部网站已实测 |
| Chrome | 扩展与 CSV 已实现；完整原生验收待补 | 同上；首次扩展加载仍需浏览器确认 |

| 微信等其他应用 | 不做专用适配 | 仅可手动尝试允许粘贴的输入框，受保护输入框排除 |

多 DPI、跨屏、断屏恢复及 Narrator 仍需人工验收，见 acceptance-report.md。

## 2026-09-20 浏览器增量

Edge/Chrome 已有 Manifest V3 扩展、本机组件及 CSV 解析代码，**浏览器实际版本未采集，原生安装和真实网站仍未验证**。不将自动化通过改写为浏览器兼容认证。填写模型测试覆盖单一登录框、已有输入、表单替换、跨域 action、到期和重复请求。跨应用输入原型与 QQ 限制不变。

## 填写触发方式补充

- xcpcai.com：已只读检查实际 Sign in 弹窗字段，新增对应受控表单回归；用户此前仅按 Tab，未通过扩展触发。正确触发是工具栏扩展或 Alt+Shift+L 后选择账号。未以真实账号登录测试。
- Steam：旧 Ctrl+Alt+P / SendInput 单项路径已移除。当前使用悬浮搜索 → 用户名复制 → 20 秒内 Tab → 密码复制，由用户自行粘贴，不自动提交。
