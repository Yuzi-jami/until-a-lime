# 直到密码变成一颗酸橙 · 前端设计参考

**Until a Lime** 是一个让密码管理变得轻松的本地应用概念。视觉借鉴苹果桌面软件的克制与清晰，用暖橙带来亲近感，用蓝色表达秩序和可靠。酸橙既是品牌记忆点，也是一种情绪：把难记的密码，变成一件不必时时惦记的小事。

## 页面结构

- **本地密码库**：左侧放品牌、导航与分组；中间以表格展示网站、账号和状态；右侧呈现选中条目的详情。浏览、筛选与查看无需反复跳页。
- **浏览器扩展**：独立展示紧凑的弹出面板，并通过网页登录场景说明自动填充与保存提示，让用户直观看到桌面端与扩展的配合方式。
- **密码生成器**：突出结果，长度与字符选项收在下方，生成和复制是主要操作。
- **设置**：以简单分组容纳外观和使用偏好，避免把低频操作挤进密码库。

## 视觉语言

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 暖橙 | `#F58B3A` | 品牌、重点入口、主视觉 |
| 蓝色 | `#4285EC` | 选中、链接、焦点与连接状态 |
| 雾白 | `#F6F8FB` | 页面底色与安静的背景层 |
| 墨色 | `#263247` | 标题和主要文字 |

橙与蓝作为少量强调色使用，正文区域保留充足白色。状态同时配文字或图标，不能只依赖颜色区分。橙子与玻璃盾牌主视觉传达温暖和守护，适合放在欢迎区域；密集操作区保持简洁。

字体优先使用系统字体：`-apple-system`、`BlinkMacSystemFont`、`Segoe UI`、`Microsoft YaHei`、`sans-serif`。正文约 14px，辅助文字 12px，页面标题 28–32px；密码使用等宽字体。间距以 8px 为基准，内容区留白 24–32px，分区之间保持 24px。按钮圆角 10–12px，卡片 18–24px，阴影柔和，边线轻薄。

## 关键交互

搜索与分类直接作用于列表；点击条目更新详情并保留选中状态。密码默认遮盖，显示与复制分别提供明确按钮；收藏、生成和保存操作应有轻量反馈。新增表单只要求必要字段，错误提示紧贴对应输入框。

扩展侧优先呈现当前网站及匹配账号，一次主要操作完成填充。保存提示说明网站和账号，并提供清晰的保存、取消入口。动效保持在 160–240ms，以透明度和小幅位移为主；键盘焦点清楚可见，窄屏下优先保留核心操作。

## 文件与后续落地

`酸橙-前端设计参考.html` 为可离线双击的单文件版本。`index.html`、`style.css`、`app.js` 与 `citrus-vault.svg` 是便于修改的拆分版本。

后续使用 React 时，可拆分为 `AppShell`、`Sidebar`、`VaultTable`、`PasswordDetail`、`ExtensionPreview`、`Generator` 与 `SettingsPanel`。颜色、圆角和间距保留为 CSS 变量，同一套按钮、输入框与提示样式贯穿桌面端及扩展；Tauri 可承载桌面界面，原生能力另行设计。

**范围说明：本交付只提供前端设计参考。所有账号和密码均为虚构数据，交互仅保留在页面内存中；不连接真实密码库，不实现浏览器扩展，也不表示已具备加密或安全存储能力。**
